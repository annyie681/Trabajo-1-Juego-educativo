# Trabajo-1-Juego-educativo
Trabajo 1 para CV - Juego Educativo

Creadores: 
Hernández Morales Anahí
López Corella David Antonio
Sandoval López Daniela

Descripción:
Es un videojuego educativo interactivo con temática espacial enfocado en operaciones matemáticas básicas. Los jugadores avanzan por diferentes niveles representados como mundos: "Campo de Suma", "Desierto de Resta", "Cosecha de Multiplicación" y "Valle de División". El juego ofrece retroalimentación inmediata (correcto/incorrecto), una tienda con personajes desbloqueables, un menú de opciones (idioma, música, efectos de sonido) y un resumen narrativo del progreso del jugador para los padres.

Información Adicional:
Creado por medio de Canva, utilizando sus herramientas para agregar audio, botones, animaciones e interactividad entre los distintos escenarios del juego. Para jugar se tienen que superar niveles de distintos mapas que contienen ejercicios de matemáticas (sumas, restas, multiplicaciones y divisiones).
